# Documentation as product

Documentation is not support material after the fact. It is a **primary output** of engineering and a continuous source of discoverable, original content.

## Every repository should contain

README · Getting Started · Architecture · ADR · API · SDK · Examples · Tutorials · Research · Benchmarks · Roadmap · FAQ · Contributing · Glossary · Reference · Release Notes

## From these, the site can generate

- Developer documentation
- Public tutorials
- SEO landing pages
- GEO-friendly knowledge articles
- Interactive architecture diagrams (D2 → SVG in CI)
- API references
- “Behind the Design” engineering stories

## Observatory link

DPO measures whether docs/hubs actually move crawl, citation, and engagement (Topic Coverage, Research Influence, Content Originality). Docs that never emit signals fail the platform loop.
