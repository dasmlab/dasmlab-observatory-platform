# Ecosystem flywheel

Each repository links to the others and back to **dasmlab.org** for documentation, architecture articles, tutorials, and commercial support.

## The loop

1. **GitHub** establishes engineering credibility.
2. **Search engines** index documentation and tutorials.
3. **AI assistants** cite original implementations (→ DPO Citation Velocity).
4. **Developers** adopt community editions.
5. Organizations that want enterprise features, hosting, customization, or support engage commercially.

```text
Research → Experiment → Prototype → Product → Usage → Metrics → Insights → Research
```

Research publications (`research/`) become backlinks, SEO, and AI citations. DPO measures the authority those publications create — the flywheel closes.

## Anti-pattern

Shipping isolated repos with no docs/knowledge edges and no Observatory feedback. That breaks the university model and the five-question loop.
